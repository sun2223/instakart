# InstaKart 🛒 — GenAI-Powered Quick-Commerce Platform

**InstaKart** is a full-stack AI-powered grocery shopping application that transforms natural language into intelligent shopping experiences.

Built with React, TypeScript, Node.js, Express, MongoDB, and LLaMA 3.1 through the Groq API, InstaKart combines Generative AI with catalog-aware product search to simplify grocery shopping.

### Key Features

- **AI Cart Builder:** Converts natural-language requests into relevant grocery suggestions using LLaMA 3.1.
- **Intelligent Product Matching:** Supports Hinglish queries, synonym resolution, and category-aware search.
- **Personalized Recommendations:** Suggests products based on user preferences, shopping history, and contextual signals.
- **Zap Mode:** Streamlined checkout with an 8-second cancellation window.
- **Real-Time Order Tracking:** Uses Socket.io for live order status updates.
- **Secure Authentication:** Account registration and login with hashed passwords and JWT.
- **Smart Product Catalog:** Search and browse grocery products across 10 categories.

### Tech Stack

**Frontend:** React 19, TypeScript, Vite, Zustand

**Backend:** Node.js, Express.js, MongoDB

**Generative AI:** LLaMA 3.1, Groq API, Prompt Engineering

**Real-Time Communication:** Socket.io
